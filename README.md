# Project-1-Azure-Storage-SolutCLDV7112 – Cloud Development B
Project 1 – Azure Storage Solution
📌 Project Overview

This project was developed as part of Cloud Development B (CLDV7112). The purpose of the project was to develop a web application that integrates different Microsoft Azure Storage Services to store and manage different types of application data.

The application demonstrates the use of Azure Table Storage, Azure Blob Storage, Azure Queue Storage and Azure Files.

☁️ Azure Services Used
Azure Service	Purpose
Azure Table Storage	Stores customer profiles and product information
Azure Blob Storage	Stores application images
Azure Queue Storage	Handles order and inventory-related messages
Azure Files	Stores application log files
Azure App Service	Hosts the web applicationion-
